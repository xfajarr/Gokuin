# AI disclosure

Per ETHOnline 2026 rules, AI tooling used on this project is disclosed here.

## Tools

- **Claude Code (Opus 5)** — problem research, architecture design, spec authoring, and code generation across contracts, backend, frontend and the Substreams module.

## Human contribution

Project direction, problem selection, measurement design, sponsor strategy and all
review/acceptance decisions were made by the team. The measurement definitions in
`packages/core/metrics.ts` were specified by hand before any implementation was generated.

## Spec-driven artifacts

Planning artifacts, prompts and design decisions are committed under `spec/` and in
[PRD.md](./PRD.md), per the ETHOnline requirement that spec files and planning artifacts
live in the repo when spec-driven workflows are used.
